# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.5.0] - 2026-02-26
### Adicionado
- Código de Conduta, Guia de Contribuição e templates de Issue/PR (fluxo profissional).
- Pipeline GitHub Actions rodando lint HTML, build Tailwind e Lighthouse CI.
- Documentação de arquitetura (`docs/architecture.md`), roadmap e seções de governança no README.
- `SECURITY.md`, política de branch protection e monitoramento documentados.
- Arquivo `_headers` com políticas de segurança (CSP, HSTS, X-Content-Type).

### Alterado
- `.gitignore` saneado para permitir documentações e ignorar artefatos dinâmicos.
- README recebeu badge de CI, roadmap e instruções de colaboração.
- Dependências dev atualizadas com htmlhint e @lhci/cli.

## [1.4.0] - 2026-01-17
### Adicionado
- Wave 1.5 visual (micro-interações, tipografia refinada, scroll storytelling).
- Métricas de performance e documentação do design system.
